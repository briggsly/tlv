## Entity Overview

**Tulsa Local Ventures (TLV)** is a GKFF (George Kaiser Family Foundation) initiative focused on economic development, venture ecosystem building, and direct investment in the Tulsa region. Briggs provides consulting services via BriggsBio, invoicing monthly since June 2025.

The organization has three operational pillars:
1. **Latam to Tulsa** — Founder relocation program bringing LatAm startups to Tulsa
2. **Economic Development** — Ecosystem gap analysis, logic modeling, venture demand analysis
3. **Portfolio** — Direct investments and VC fund investments

## Key Findings

### Where Everything Lives Now

The **primary data store for TLV operations is OneDrive** (`OneDrive-GKFFEnterpriseServices/`). It holds the complete operational record: portfolio company files, thesis docs, IC materials, ecosystem analysis, budget, HR, legal documents, and the Latam to Tulsa program.

Dropbox holds historical presentations (Jun-Nov 2025), BriggsBio invoices, and earlier versions of spreadsheets/models — mostly a superset of what's in OneDrive with some unique legacy documents.

The local `~/Projects/tlv/` directory is essentially empty except for the standalone investment triage tool.

### Gaps / Issues

1. **No Notion workspace** — TLV lacks a structured knowledge management system. PML has Notion; TLV does not.
2. **No local mirror** — The OneDrive content is cloud-only. If OneDrive sync breaks or access changes, all data is at risk.
3. **No task tracking** — No TLV tasks in briggshome-workspace or GitHub issues.
4. **No LINK.md** — No mapping from local path → GitHub → Notion for TLV.
5. **Empty files** — Several `.txt` and `.md` files in Dropbox are 0-byte empties (Agentification Workplan, Strategic Plan).
6. **Project registry stale path** — `projects/index.yaml` points to a Dropbox+paperclipai path that never existed.
7. **No Apple ecosystem presence** — TLV not in Notes or Reminders.
8. **Portfolio company details are in OneDrive but not cataloged** — individual company subfolder structures need an agent to walk through.
9. **VC Fund allocation tracking** exists in Portfolio/VC Funds/ but no easy rollup.

### Suggested Structure for Centralized TLV Project

```
~/Projects/tlv/
├── TLV-INVENTORY.md              ← This file
├── docs/
│   ├── thesis/                   ← Investment thesis PDFs/links
│   ├── IC/                       ← Investment committee materials
│   └── ecosystem/                ← Ecosystem analysis reports
├── portfolio/
│   ├── companies/                ← Per-company briefs or index
│   └── funds/                    ← VC fund tracking
├── tools/
│   ├── tlv_investment_triage.html ← Investment triage tool
│   └── (other tools)
├── ops/
│   ├── invoices/                 ← BriggsBio invoice tracking
│   └── contact-list/             ← TLV contact directories
├── latam-to-tulsa/
│   ├── founders/                 ← Founder tracking
│   └── program/                  ← Program docs
└── link.yaml                     ← Maps local → GitHub → OneDrive → Notion
```

The key decision is: **should OneDrive remain the primary store with local indexing, or should there be a local mirror?** Given the volume (hundreds of files across 4 workspaces), recommend indexing + local reference docs rather than mirroring everything.
